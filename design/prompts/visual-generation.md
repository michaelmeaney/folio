# Visual Generation Instructions

Use the Folio design system as a hard constraint.

The generated image is a visual specification for reconstruction, not the final presentation artefact.

## Before generating

1. Resolve the slide's semantic message.
2. Select an archetype.
3. Lay out foreground text and functional visuals first.
4. Identify the remaining negative-space regions.
5. Inspect the approved component catalogue and reuse its visual vocabulary.
6. Add background atmosphere only where negative space permits it.

## Generation prompt

Create a 16:9 premium minimalist editorial presentation slide.

Strictly follow the supplied Folio design tokens and approved component catalogue. Do not invent fonts, colours, component styles or layout conventions.

Use Inter typography with the exact hierarchy defined in DESIGN.md. Use the defined off-white background, slate foreground and registered accent colours only.

Prefer asymmetrical editorial composition, substantial intentional whitespace, one dominant idea, restrained thin-line vector language and simple diagrams.

Background atmosphere is compositional. Place soft blurred geometry only after foreground composition is established. It must occupy negative space, prefer slide edges/corners, sit visually behind all functional content and never compete with text or the primary visual.

Reuse approved catalogue components when they exist. If a required visual primitive does not exist, propose one novel component consistent with the system and make it visually separable for later vectorisation.

Avoid generic PowerPoint templates, dense card grids, excessive rounded rectangles, small text, arbitrary gradients, stock photography, decorative icons beside bullets and infographic-style overpacking.
