# Implementation record

Implementation documents connect intent to shipped code. Track source locations, verification evidence, current status, debt and follow-up here. Documentation alone never qualifies a capability as implemented.

Use `implementation-<nnn>-<kebab-case-title>.md` for delivery records and `debt-<nnn>-<kebab-case-title>.md` for explicit unresolved work. Keep links back to the originating vision, idea, PRD, ADR and plan.
