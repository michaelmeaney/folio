# Practical benchmark quality delivery

Implements [ADR 003](../architecture/adr-003-practical-benchmark-quality.md) as a follow-up to [PRD 003](../prds/prd-003-folio-bench-go.md).

1. Version the practical suite and annotate reference purpose/relationship scope.
2. Extend the evaluator with separate dimensions and evidence-backed minor observations; preserve strict legacy diagnostics.
3. Make attached connectors case-specific and document the practical editing milestone in Folio references.
4. Add an independent review allowance, preserving generation and partial findings on review timeout.
5. Expose phase outcomes/dimensions in text and HTML reports, and retain runtime comparison safeguards.
6. Validate semantic policy, connector opt-in, stale evidence, technical failures, phase budgets and timeout persistence; build/install the CLI and refresh Codex/Claude plugin caches.

Real generation is not automatically rerun by this delivery. Saved prior decks/results remain under their original frozen policies.
