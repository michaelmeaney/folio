# Plans

Plans sequence approved work into deliverable steps, owners, dependencies, verification and operational follow-up. A plan may link to several PRDs and ADRs, but should not introduce an unrecorded product decision.

Use the filename form `plan-<nnn>-<kebab-case-title>.md` and the `plan` type slug.
